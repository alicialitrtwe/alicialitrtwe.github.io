Bayesian

Every model here is fit to predict something measured. This area is about what you may then conclude from its parameters.

A model can predict well and still support no conclusion. When its features are correlated, many different settings of the weights produce the same prediction, so the weights a fit returns are one choice among many that the data cannot separate. Accuracy does not reveal this, because accuracy is identical for all of them.

This is a property of the basis, not of the fit. If the features are sparse and non-negative, with one interpretable direction per coordinate, the weights become identifiable, and reading them off is a measurement rather than an interpretation of an arbitrary point.

Sparse concept atoms 2021–2025

Word embeddings predict cortical responses well. They also carry more semantic factors than they have dimensions, so the factors share directions, and a voxel’s weights cannot be attributed to any one of them. Sparse dictionary learning rewrites the embedding as a thousand non-negative concept atoms, one interpretable direction per atom. Prediction accuracy is unchanged; the difference is that the weights can now be read an atom at a time. The video shows what the models are fit to: measured responses while a story plays.

  • Disentangling Superpositions: Interpretable Brain Encoding Model with Sparse Concept Atoms NeurIPS 2025

    Alicia Zeng, Jack Gallant

    OpenReview·Talk·Code·Cite·Explainer

The talkNeurIPS 2025, five minutes

Five minutes on the same argument: why dense embeddings leave voxel weights unreadable, what sparse dictionary learning does about it, and what the resulting maps show. Recorded at the conference, and also on SlidesLive.

Transcript of the talk

We use interpretable AI models to understand how the brain represents abstract ideas — like time, space, and number. Let’s start with the basic tool behind this work: fMRI voxelwise encoding models. fMRI, or functional Magnetic Resonance Imaging, measures tiny changes in blood oxygenation levels across the brain. Every second or so, we simultaneously record signals from tens of thousands of small brain volumes, called voxels. To visualize the complex data, we computationally inflate and flatten the cerebral cortex into a 2D map. Anything you perceive in the story — whether it’s a sound, a word, or even a fleeting emotion or memory — should leave a trace somewhere in the brain’s activity patterns.

The purpose of an encoding model is to learn a mapping between what’s happening in the stimulus, and how the brain responds. Mathematically, we describe this using two matrices: X, which represents the features of the stimulus, and Y, the measured brain responses. We then fit a model — typically regularized linear regression — to predict Y from X. And we do this separately for each voxel. That’s what makes it voxelwise. When the model is trained, every voxel ends up with a weight vector — an arrow pointing through the feature space, telling us which features that voxel cares about.

The hardest part of building an encoding model is turning something as rich as a story into numbers. A major leap in prediction performance came when researchers began using features from machine learning, like word embeddings or activations from large language models. But we end up explaining one black box with another. The loss of interpretability comes partly from a phenomenon called superposition. Neural networks have to represent millions of concepts using only limited dimensions, so each concept is encoded as a linear combination of shared directions. In this feature space, concepts like time and number can be correlated, so a weight vector that points toward “number” will also point toward “time.”

This isn’t just theoretical — it shows up in real data. On this cortical flatmap, some regions respond to time, number, and space words all at once. But we can’t tell whether that overlap reflects a shared neural code or just correlations in the embedding space.

So how might we start to untangle this? Superposition happens when too many features are crammed into too few dimensions. To address that, we need to unpack them — to recover the hidden semantic directions and give each one its own coordinate. In other words, we expand the feature space into a higher-dimensional one, where different concepts can be separated cleanly. Each word then becomes a weighted mix of just a few of these latent directions. This works because of one key assumption: sparsity. Most words connect to only a few underlying concepts, so we expect most entries in this new representation to be zero. This standard approach is known as sparse coding. The result is a new, more interpretable representation of the stimulus — a sparse activation matrix.

Now that we have this new sparse representation, we can plug it back into the fMRI encoding model. Before, we used dense embeddings directly in a linear regression. Now, we replace them with these sparse features. Each voxel’s weight vector now lives in an interpretable space, where every axis corresponds to a distinct concept. That means we can read out what each voxel selects for directly, and map those patterns across the cortex.

Now we can return to the question we started with: where in the brain are time, space, and number represented? This isn’t just a fun example. It also tests a long-standing idea in psychology: that these three concepts may share a common magnitude system in the brain. To explore that, we identify the concept atoms for time, space, and number and create cortical maps showing where each is represented. For each subject, we layer the three maps together to reveal their overlap.

White areas show the three-way overlap, highlighting voxels that respond to all three concepts. What we find is intriguing. There is bilateral overlap in regions such as the intraparietal sulcus and the inferior frontal gyrus, a pattern consistent with the idea of a shared magnitude system. By unpacking these dense representations, we are beginning to see how abstract ideas like time, space, and number are organized across the brain.
